TROUBLESHOOTING:
---------------
500 Error:
  → Check django_errors.log
  → Verify .env database credentials
  → Check ALLOWED_HOSTS
  → Restart app in cPanel

No CSS:
  → python manage.py collectstatic --noinput --clear
  → chmod -R 755 staticfiles
  → Restart app

Database Error:
  → Check database name has username prefix
  → Verify user has ALL PRIVILEGES
  → Test: python manage.py dbshell

Module Not Found:
  → pip install -r requirements.txt --force-reinstall
  → Restart app

CONFIGURATION FILES:
-------------------
.env                    → Environment variables (MUST CONFIGURE!)
.htaccess              → Apache config (update username)
passenger_wsgi.py      → WSGI entry point
requirements.txt       → Python dependencies
fagicrm/settings_production.py → Production settings

MUST CONFIGURE IN .env:
----------------------
SECRET_KEY=your-unique-random-key
DEBUG=False
ALLOWED_HOSTS=fagicrm.fagitone.com,www.fagicrm.fagitone.com
DB_NAME=yourusername_fagicrm
DB_USER=yourusername_fagicrm_user
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=3306

DATABASE SETUP (cPanel):
-----------------------
1. cPanel → MySQL Databases
2. Create Database: fagicrm
3. Create User: fagicrm_user (set password)
4. Add User to Database (ALL PRIVILEGES)
5. Note: Names will be prefixed with your username

PYTHON APP SETUP (cPanel):
--------------------------
1. cPanel → Setup Python App
2. Create Application
3. Python Version: 3.9+
4. App Root: /home/yourusername/fagicrm.fagitone.com
5. Startup File: passenger_wsgi.py
6. Entry Point: application

EMERGENCY FIXES:
---------------
# If app won't start
1. Check django_errors.log
2. Verify .env file exists and is correct
3. Check database credentials
4. Reinstall dependencies: pip install -r requirements.txt
5. Restart app in cPanel

# If static files missing
1. python manage.py collectstatic --noinput --clear
2. chmod -R 755 staticfiles
3. Check .htaccess configuration
4. Restart app

# If database errors
1. Verify database exists in cPanel
2. Check user has privileges
3. Test connection: python manage.py dbshell
4. Check .env credentials match cPanel

# If permission errors
1. find . -type d -exec chmod 755 {} \;
2. find . -type f -exec chmod 644 {} \;
3. chmod -R 777 media
4. chmod +x *.sh
