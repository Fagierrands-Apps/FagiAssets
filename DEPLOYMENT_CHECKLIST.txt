└──────────────────────────────────────────────────────────────────────────────┘

500 Internal Server Error:
→ tail -f ~/logs/error_log

Static files not loading:
→ cd ~/fagiassets/assetmanagement
→ python manage.py collectstatic --noinput --clear
→ Restart app in cPanel

Database connection error:
→ Check .env file: cat ~/fagiassets/.env | grep DB_
→ Test: cd ~/fagiassets/assetmanagement && python manage.py check --database default

Permission denied:
→ chmod -R 755 ~/fagiassets
→ chmod -R 775 ~/fagiassets/assetmanagement/media

Module not found:
→ source ~/virtualenv/fagiassets/3.11/bin/activate
→ pip install -r ~/fagiassets/requirements.txt
