                              TROUBLESHOOTING PATHS
═══════════════════════════════════════════════════════════════════════════════

Problem: 500 Internal Server Error
│
├─→ Check Django error log: ~/fagiassets/assetmanagement/django_errors.log
├─→ Check Apache error log: ~/logs/error_log
├─→ Verify database credentials in .env
├─→ Check ALLOWED_HOSTS includes your domain
└─→ Restart Python app in cPanel


Problem: Static Files Not Loading
│
├─→ Run: python manage.py collectstatic --noinput
├─→ Check .htaccess configuration
├─→ Verify file permissions (755 for dirs, 644 for files)
└─→ Restart Python app in cPanel


Problem: Database Connection Error
│
├─→ Verify credentials in .env file
├─→ Test: python manage.py dbshell
├─→ Check PostgreSQL is running
├─→ Verify user has correct privileges
└─→ Check database exists


Problem: Module Not Found
│
├─→ Activate virtual environment
├─→ Run: pip install -r requirements.txt --force-reinstall
└─→ Restart Python app in cPanel


Problem: Permission Denied
│
├─→ Run: chmod -R 755 ~/fagiassets
├─→ Run: chmod -R 777 ~/fagiassets/assetmanagement/media
├─→ Run: chmod -R 777 ~/fagiassets/assetmanagement/staticfiles
└─→ Run: chmod +x ~/fagiassets/cpanel_deploy.sh
