================================================================================
HOW IT WORKS
================================================================================

1:30 PM - LUNCH BREAK:
----------------------
- All clocked-in employees are automatically clocked out
- They are immediately clocked back in (1 second later)
- Work continues seamlessly
- Lunch break is properly tracked

10:00 PM - END OF DAY:
----------------------
- All clocked-in employees are automatically clocked out
- Work session is marked as complete
- Employees must manually clock in the next day

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Access Denied" when creating tasks
Solution: Run PowerShell as Administrator

Problem: Tasks not running
Solution: 
1. Open Task Scheduler (taskschd.msc)
2. Find "CRM Auto Clock-Out" tasks
3. Check "History" tab for errors
4. Verify Python path is correct

Problem: Employees not being clocked out
Solution:
1. Verify employees are clocked in
2. Check employee status is 'active'
3. Run: python manage.py auto_clockout --force
