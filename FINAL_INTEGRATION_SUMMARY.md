## 🛠️ **How to Use**

### **Start the System**
```bash
cd assetmanagement
python manage.py runserver
```

### **Access the System**
1. Open browser to http://localhost:8000/
2. Login with your credentials
3. Navigate between modules using the sidebar
4. CRM features are at http://localhost:8000/crm/

## 📊 **Typical Workflows**

### **1. Customer Asset Assignment**
```
CRM → Add Customer → Assets → Assign to Customer → Track Assignment
```

### **2. Lead to Customer Conversion**
```
CRM → Create Lead → Qualify → Convert to Customer → Assign Assets
```

### **3. Employee Asset Management**
